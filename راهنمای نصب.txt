دفتر آرزوها – نسخه اصلاح‌شده ورود ابری

۱) در GitHub مخزن daftar-arzooha را باز کنید.
۲) Add file → Upload files را بزنید.
۳) سه فایل داخل این پوشه (index.html، manifest.webmanifest و sw.js) را انتخاب و بارگذاری کنید تا فایل‌های قبلی جایگزین شوند.
۴) پایین صفحه Commit changes را بزنید.
۵) پس از حدود ۱ تا ۳ دقیقه سایت را با Ctrl+F5 تازه‌سازی کنید.

نکته: این نسخه از همان نشانی پروژه و کلید عمومی Supabase که در نسخه قبلی تنظیم شده استفاده می‌کند. چون جدول‌های admin_users و wishlist_cloud در پروژه شما ساخته شده‌اند، فعلاً SQL را دوباره اجرا نکنید.

ورود مدیر: ایمیل و رمز عبوری که در Supabase → Authentication → Users ساخته‌اید.
خانواده: پس از ورود مدیر، دکمه «ساخت لینک خانوادگی» را بزنید و لینک را ارسال کنید.
